# النخبة لإدارة المولدات والجباية — النسخة الواضحة

تطبيق Flutter واحد لصاحب المولدة والجابي، بمسار مباشر بدون طبقات مالية معقدة.

## المسار

1. فتح دورة قراءات.
2. الجابي يسجل القراءات.
3. صاحب المولدة يقفل الدورة.
4. يحدد سعر الأمبير.
5. ينشئ فواتير الشهر.
6. يفتح الفاتورة ويسجل دفعة.
7. يظهر المدفوع والمتبقي ورقم الوصل داخل نفس البطاقة.

الفاتورة نفسها تمثل الدين. لا توجد مسودات أو اعتماد منفصل أو دفتر ذمم أو صفحة صندوق.

## التسديد

- دفع كامل أو جزئي.
- طريقة الدفع: نقد أو تحويل.
- منع دفع مبلغ أكبر من المتبقي.
- كل دفعة لها رقم وصل.
- سجل الدفعات ظاهر تحت الفاتورة.
- لا طباعة ولا إرجاع دفعة ولا صندوق في Stage06.

## الثوابت

- Base URL: `https://modeer-app.onrender.com`
- لا تسجيل ذاتي.
- لا GPS أو تتبع موقع.
- لا إشعارات أو واتساب.
- القراءة Offline-First، أما إنشاء الفواتير والتسديد فيحتاجان اتصالًا.
