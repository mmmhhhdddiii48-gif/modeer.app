# النخبة لإدارة المولدات والجباية — النسخة الواضحة

تطبيق Flutter واحد لصاحب المولدة والجابي. هذه النسخة تعتمد مسارًا مباشرًا بدون طبقات مالية معقدة.

## المسار

1. فتح دورة قراءات.
2. الجابي يسجل القراءات.
3. صاحب المولدة يقفل الدورة.
4. يحدد سعر الأمبير لكل مولدة.
5. يضغط **إنشاء فواتير الشهر**.
6. تظهر الفواتير غير المسددة.

الفاتورة غير المسددة هي الدين نفسه. لا توجد مسودات، مراجعة، اعتماد منفصل، أو دفتر ذمم مستقل.

## الثوابت

- Base URL: `https://modeer-app.onrender.com`
- لا تسجيل ذاتي.
- لا GPS أو تتبع موقع.
- لا إشعارات أو طباعة أو واتساب.
- لا قبض أو وصولات في هذه النسخة.
- القراءة Offline-First، أما إنشاء الفواتير فيحتاج اتصالًا.

## التشغيل

