# النخبة لإدارة المولدات والجباية Mobile — Stage06

تطبيق Flutter واحد لـAndroid وiPhone. Stage06 يضيف اعتماد الفاتورة وفتح سجل الذمم فوق دورات القراءة ومسودات الفواتير.

## الثوابت

- Base URL ثابت: `https://modeer-app.onrender.com`
- وحدة السيرفر: `/generators/...`
- لا تسجيل ذاتي.
- لا GPS أو تتبع موقع.
- لا إشعارات أو طباعة أو واتساب.
- القبض والوصولات وتأثير الصندوق غير مفعلة.

## ما تم تفعيله

- اعتماد مسودة مراجَعة فقط كفاتورة ثابتة.
- رقم فاتورة فريد داخل المؤسسة.
- إنشاء قيد مدين داخل سجل الذمم بقيمة الفاتورة نفسها.
- حفظ Snapshot كامل للفترة والمشترك والمولدة والقراءة والتسعيرة والمبلغ.
- إعادة اعتماد المسودة نفسها تعيد الفاتورة الموجودة ولا تكررها.
- الفاتورة وسجل الذمة غير قابلين للتعديل أو الحذف في Stage06.
- عرض الفواتير والذمم لصاحب المولدة فقط.
- الجابي لا يرى الفواتير أو الذمم ولا يستطيع القبض.
- البيانات المؤكدة تُحفظ في Cache للعرض عند انقطاع الإنترنت.

## تجهيز Android وiOS على Windows

شغّل:

```text
bootstrap_flutter.cmd
flutter pub get
flutter analyze
flutter test
flutter run
```

## بناء Android

```text
flutter build apk --release
flutter build appbundle --release
```

## iPhone

ملفات iOS تُجهز من Flutter، لكن البناء والتوقيع والفحص الفعلي يحتاج Mac وXcode.
