# النخبة لإدارة المولدات والجباية — النسخة الواضحة

تطبيق Flutter واحد لصاحب المولدة والجابي، بمسار مباشر بدون طبقات مالية معقدة.

## المسار

1. فتح دورة قراءات.
2. الجابي يسجل القراءات.
3. صاحب المولدة يقفل الدورة.
4. يحدد سعر الأمبير.
5. ينشئ فواتير الشهر.
6. صاحب المولدة أو الجابي المكلّف يسجل دفعة.
7. يظهر المدفوع والمتبقي ورقم الوصل داخل بطاقة الفاتورة.

الفاتورة نفسها تمثل الدين. لا توجد مسودات أو اعتماد منفصل أو دفتر ذمم أو صفحة صندوق.

## تحصيل الجابي

- الجابي يرى فقط الفواتير التابعة لمولدة أو مسار أو مشترك مكلّف به.
- دفع كامل أو جزئي.
- طريقة الدفع: نقد أو تحويل.
- كل دفعة لها رقم وصل.
- اسم مستلم الدفعة يظهر لصاحب المولدة.
- التحصيل يحتاج اتصالًا بالسيرفر.
- لا يوجد تحصيل Offline في Stage07.

## الثوابت

- Base URL: `https://modeer-app.onrender.com`
- لا تسجيل ذاتي.
- لا GPS أو تتبع موقع.
- لا إشعارات أو واتساب.
- القراءات Offline-First.
- إنشاء الفواتير والتسديد والتحصيل تحتاج اتصالًا.
