# النخبة لإدارة المولدات والجباية Mobile — Stage03

تطبيق Flutter واحد لـ Android وiPhone، مرتبط بوحدة `/generators` داخل السيرفر الحالي:

`https://modeer-app.onrender.com`

## المنفذ حتى Stage03

- تسجيل دخول صاحب المولدة والجابي مع Access/Refresh Token وSecure Storage.
- SQLite محلية وQueue للمزامنة Offline-First.
- صاحب المولدة ينشئ الجباة ضمن الحد المحدد له ويدير حالاتهم وصلاحياتهم.
- إدارة مولدات حقيقية: الرمز، الاسم، المنطقة، السعة، الطور والحالة.
- إدارة مسارات حقيقية مع ربط اختياري بمولدة.
- إدارة مشتركين حقيقيين مع ربط إلزامي بمولدة وربط اختياري بمسار متوافق.
- تخصيص الجابي من Catalog حقيقي فقط؛ لا يمكن كتابة معرف أو اسم مزور من التطبيق.
- الجابي يرى فقط المولدات والمسارات والمشتركين الناتجين عن تخصيصاته.
- آخر بيانات مؤكدة تحفظ محليًا وتبقى قابلة للعرض عند انقطاع الإنترنت.

## ما يزال مقفولًا

- قراءة العداد.
- الجباية الكاملة أو الجزئية.
- الفواتير والديون والمصاريف والأرباح.
- ربط برنامج الحاسبة.
- GPS والإشعارات والطباعة وواتساب.
- الحذف الصلب للسجلات؛ التغيير يتم بالحالة حفاظًا على العلاقات وAudit Log.

## تجهيز Android وiOS على Windows

```text
bootstrap_flutter.cmd
```

ثم:

```bash
flutter run
flutter build apk --release
flutter build appbundle --release
```

مجلد iOS يجهز من Flutter نفسه، لكن بناء وتوقيع وفحص نسخة iPhone الفعلية يحتاج Mac وXcode.
