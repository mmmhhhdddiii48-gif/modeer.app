# النخبة لإدارة المولدات والجباية Mobile — Stage05

تطبيق Flutter واحد لـAndroid وiPhone. Stage05 يضيف تسعير الأمبير ومسودات الفواتير الشهرية القابلة للمراجعة فوق دورة القراءة Offline-First.

## الثوابت

- Base URL ثابت: `https://modeer-app.onrender.com`
- وحدة السيرفر: `/generators/...`
- لا تسجيل ذاتي.
- لا GPS أو تتبع موقع.
- لا إشعارات أو طباعة أو واتساب.
- لا قبض أو دين أو وصل أو تأثير على الصندوق.

## ما تم تفعيله

- صاحب المولدة يختار دورة قراءة مقفلة.
- يحدد سعر الأمبير ورسمًا ثابتًا اختياريًا لكل مولدة لديها قراءات مؤكدة.
- الحساب المعتمد: `الأمبير المتعاقد × سعر الأمبير + الرسم الثابت`.
- لا يمكن توليد المسودات قبل قفل دورة القراءة.
- لا يمكن تعديل التسعيرة بعد توليد مسودات المولدة.
- كل مسودة تحفظ لقطة الاسم ورقم الحساب والعداد والأمبير والتسعيرة والقراءة والاستهلاك.
- إعادة التوليد لا تكرر المسودات.
- المسودة يمكن تعليمها `draft` أو `reviewed` فقط.
- آخر قوائم ومساحة فوترة مؤكدة تحفظ في SQLite cache للعرض بدون إنترنت.

## تجهيز Android وiOS على Windows

شغّل:

```text
bootstrap_flutter.cmd
```

ثم:

```text
flutter pub get
flutter analyze
flutter test
flutter run
```

## بناء Android

```text
flutter build apk --release
flutter build appbundle --release
```

## iPhone

ملفات iOS تُجهز من Flutter، لكن البناء والتوقيع والفحص الفعلي يحتاج Mac وXcode. لا تعتبر نسخة iPhone مفحوصة من Windows.
