# النخبة لإدارة المولدات والجباية Mobile — Stage02

مشروع Flutter مستقل يعمل بكود واحد لـAndroid وiOS. Stage02 يضيف إدارة حسابات الجباة بواسطة صاحب المولدة وعرض التخصيصات، مع استمرار قاعدة SQLite المحلية وSecure Storage ومحرك المزامنة Offline-First من Stage01.

## الثوابت

- Base URL: `https://modeer-app.onrender.com`
- وحدة السيرفر: `/generators/...`
- لا يوجد تسجيل ذاتي لصاحب المولدة.
- حساب الجابي ينشئه صاحب المولدة ضمن الحد المحدد في الاشتراك.
- لا يوجد GPS أو تتبع موقع.
- القراءات والجبايات والفواتير المالية غير مفعلة في Stage02.

## وظائف Stage02 في التطبيق

### صاحب المولدة

- مشاهدة حد الجباة والمستخدم والمتبقي.
- إنشاء حساب جابي.
- تعديل الاسم واسم المستخدم والهاتف.
- تفعيل أو إيقاف أو تعطيل الحساب.
- تحديد الصلاحيات المسموحة.
- تغيير كلمة المرور وإبطال الجلسات القديمة.
- إدارة تخصيصات مرجعية للمولدات أو المشتركين أو المسارات.
- مشاهدة آخر وقت استلام مزامنة من السيرفر.
- عرض آخر قائمة جباة محفوظة محليًا عند انقطاع الإنترنت.

### الجابي

- الدخول بحسابه.
- مشاهدة التخصيصات الخاصة به فقط.
- مشاهدة حالة الإنترنت.
- عرض آخر تخصيصات محفوظة محليًا عند انقطاع الإنترنت.
- تنفيذ مزامنة يدوية لمحرك Queue الأساسي.

## تجهيز Android وiOS على Windows

1. ثبّت Flutter Stable وAndroid Studio وفعّل Android SDK.
2. من هذا المجلد شغّل:

```text
bootstrap_flutter.cmd
```

الملف ينشئ مجلدي `android` و`ios` من Flutter الرسمي، يثبت Android minSdk على 24، ثم ينفذ:

```text
flutter pub get
flutter analyze
flutter test
```

## التشغيل

```bash
flutter run
```

## بناء Android

```bash
flutter build apk --release
flutter build appbundle --release
```

## iPhone

كود iOS ومجلده يجهزان من البداية، لكن البناء والتوقيع والفحص الفعلي يجب أن يتم لاحقًا على Mac مع Xcode. لا تعتبر نسخة iPhone مفحوصة من Windows.

## الأمان

- Access Token وRefresh Token داخل `flutter_secure_storage` فقط.
- Logout يحاول إلغاء Refresh Token من السيرفر، ثم يمسح الجلسة المحلية حتى عند انقطاع الإنترنت.
- كلمات المرور تحفظ Hash في السيرفر.
- `tenant_id` يؤخذ من التوكن ولا يقبل من واجهة Flutter.
- صلاحيات الجابي تتحقق في السيرفر في كل طلب.
- تغيير حالة الجابي أو صلاحياته أو كلمة مروره يلغي Refresh Tokens القديمة.
- SQLite مخصصة للكاش وQueue والحركات المحلية، ولا تحفظ كلمات المرور أو التوكنات.
