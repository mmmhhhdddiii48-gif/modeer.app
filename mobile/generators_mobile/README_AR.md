# النخبة لإدارة المولدات والجباية Mobile — Stage04

تطبيق Flutter واحد لـAndroid وiPhone. Stage04 يضيف دورة قراءة العداد Offline-First فوق أساس الحسابات والمولدات والمسارات والمشتركين والجباة.

## الثوابت

- Base URL ثابت: `https://modeer-app.onrender.com`
- وحدة السيرفر: `/generators/...`
- لا تسجيل ذاتي.
- لا GPS أو تتبع موقع.
- لا إشعارات أو طباعة أو واتساب.
- الفواتير والديون والجباية والمصاريف والأرباح غير مفعلة.

## ما تم تفعيله

- صاحب المولدة يفتح دورة قراءة شهرية واحدة بصيغة `YYYY-MM`.
- الجابي يرى المشتركين المكلف بهم ضمن الدورة المفتوحة.
- القراءة تحفظ محليًا في SQLite مع UUID قبل محاولة الإرسال.
- Queue حالات: `pending`, `sending`, `synced`, `failed`, `conflict`.
- المزامنة تلقائية عند رجوع الإنترنت ويدوية من زر المزامنة.
- السيرفر يمنع تكرار UUID ويعيد نفس النتيجة عند إعادة الإرسال.
- إذا تغيرت القراءة السابقة على السيرفر تظهر حالة تعارض ولا يحدث استبدال صامت.
- قفل الدورة يمنع القراءات الجديدة ولا ينشئ فاتورة أو دينًا.
- وقت الجهاز يحفظ للمعلومة، أما قبول القراءة وقفل الدورة فيعتمدان على وقت وقواعد السيرفر.

## تجهيز Android وiOS على Windows

شغّل:

```text
bootstrap_flutter.cmd
```

ثم:

```text
flutter pub get
flutter analyze
flutter test
flutter run
```

## بناء Android

```text
flutter build apk --release
flutter build appbundle --release
```

## iPhone

ملفات iOS تُجهز من Flutter، لكن البناء والتوقيع والفحص الفعلي يحتاج Mac وXcode. لا تعتبر نسخة iPhone مفحوصة من Windows.
