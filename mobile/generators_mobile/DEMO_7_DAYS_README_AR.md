# نسخة النخبة التجريبية لإدارة المولدات والجباية — 7 أيام

## الهدف

هذه نسخة Android تجريبية مستقلة تعمل بدون Render أو إنترنت، ومخصصة للعرض على الزبون قبل تفعيل النسخة الكاملة.

## مدة التجربة

- تبدأ مدة 7 أيام من أول تشغيل على الجهاز.
- إعادة البيانات النموذجية لا تعيد مدة التجربة.
- عند انتهاء المدة يتوقف الدخول إلى صفحات البرنامج.
- يوجد فحص محلي لتغيير ساعة الجهاز إلى الخلف.

> ملاحظة: لأن النسخة تعمل بدون سيرفر، حماية المدة محلية وليست بديلًا عن تفعيل النسخة التجارية عبر السيرفر.

## الحسابات التجريبية

لا توجد كلمة مرور. من شاشة البداية يمكن اختيار:

- الدخول كصاحب مولدة.
- الدخول كجابي.

## الوظائف المتاحة بدون إنترنت

- داشبورد صاحب المولدة.
- مولدات ومسارات نموذجية.
- عرض المشتركين والبحث عنهم.
- إضافة مشترك تجريبي.
- عرض فواتير الشهر وحالاتها.
- تسجيل دفعة كاملة أو جزئية.
- إنشاء رقم وصل محلي.
- إظهار اسم مستلم الدفعة.
- عرض الجباة ومسارات كل جابي.
- حساب جابي لا يرى إلا المسارات المخصصة له.
- تسجيل قراءة عداد محلية.
- إعادة البيانات النموذجية.

## العزل عن نسخة البيع

- نقطة التشغيل التجريبية: `lib/demo_main.dart`.
- نقطة التشغيل الأساسية تبقى: `lib/main.dart`.
- لا يتم تغيير Base URL أو مسارات السيرفر.
- لا يتم دمج وضع الديمو داخل منطق نسخة البيع.
- معرف Android للديمو مستقل: `com.nukhba.generatorsdemo`.

## بناء APK

يوجد GitHub Actions Workflow:

```text
.github/workflows/build-generators-demo-apk.yml
```

الناتج:

```text
Nukhba_Generators_Demo_7_Days_v1.0.0.apk
```

مع ملف SHA256 للتحقق من سلامة الملف.
