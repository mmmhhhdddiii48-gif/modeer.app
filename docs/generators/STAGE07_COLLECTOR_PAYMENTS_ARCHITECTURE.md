# معمارية Stage07 — تحصيل الجابي المباشر Online

## المسار

```text
الجابي يفتح تحصيل الفواتير
→ يرى فقط الفواتير المكلّف بها
→ يسجل دفعة كاملة أو جزئية
→ تتحدث الفاتورة
→ يظهر رقم الوصل
```

## عزل التخصيصات

السيرفر يتحقق من جدول `generator_collector_assignments` في كل عرض ودفع:

- تخصيص مولدة: يسمح بفواتير مشتركي المولدة.
- تخصيص مسار: يسمح بفواتير مشتركي المسار.
- تخصيص مشترك: يسمح بفواتير المشترك فقط.

معرفة رقم فاتورة خارج التخصيص لا تكفي؛ العملية تُرفض بـ`COLLECTOR_INVOICE_NOT_ASSIGNED`.

## البساطة

- نفس جدول الفواتير ونفس جدول الدفعات.
- لا دفتر ذمم مستقل.
- لا صندوق أو إغلاق جابي.
- لا طباعة.
- لا تحصيل Offline.
- لا شاشة مالية جديدة لصاحب المولدة.

## الأمان

- صلاحيات الجابي مطلوبة.
- المؤسسة مأخوذة من التوكن.
- `operation_uuid` يمنع تكرار نفس الدفعة.
- إعادة UUID على فاتورة أخرى تُرفض بـ`PAYMENT_OPERATION_CONFLICT`.
- صاحب المولدة يرى اسم وصفة مستلم الدفعة.
