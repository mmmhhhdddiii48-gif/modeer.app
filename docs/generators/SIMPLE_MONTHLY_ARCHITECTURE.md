# معمارية النسخة الواضحة

## القرار

تم رفض Stage05 وStage06 المعقدتين كمسار عمل للمستخدم. النسخة الجديدة مبنية مباشرة فوق Stage04 المعتمدة.

## الدورة الوحيدة

```text
قراءات العداد
→ قفل الشهر
→ تحديد سعر الأمبير
→ إنشاء فواتير الشهر
→ الفواتير تظهر غير مسددة
```

## البيانات

يوجد جدولان فقط:

- `generator_monthly_prices`: سعر الأمبير والرسم الثابت لكل مولدة في الشهر.
- `generator_monthly_invoices`: الفواتير النهائية غير المسددة.

الفاتورة غير المسددة تمثل دين المشترك. لا يوجد جدول مسودات، ولا مراجعة، ولا اعتماد منفصل، ولا سجل ذمم مستقل.

## الحماية

- لا إنشاء قبل قفل القراءات.
- لا إنشاء قبل تحديد الأسعار.
- إعادة الإنشاء لا تكرر الفواتير.
- لا تغيير للسعر بعد إنشاء الفواتير.
- المؤسسة مأخوذة من التوكن.
- لا قبض أو وصل أو صندوق في هذه النسخة.
