# معمارية Stage03 — المولدات والمشتركين والمسارات

## الهدف

تحويل تخصيصات Stage02 من مراجع نصية أولية إلى أهداف حقيقية داخل قاعدة البيانات، مع تثبيت عقود المولدات والمسارات والمشتركين قبل فتح القراءة أو الجباية المالية.

## الجداول الجديدة

### generator_units

يمثل المولدة داخل مؤسسة واحدة. أهم الحقول: `public_id`, `tenant_id`, `code`, `name`, `area`, `address`, `capacity_kva`, `phase_type`, `status`, `notes`.

- الكود فريد داخل المؤسسة.
- الحالات: `active / inactive / maintenance`.
- لا توجد حقول أرباح أو جباية أو فواتير.

### generator_routes

يمثل مسار الجباية أو التوزيع، ويمكن ربطه بمولدة واحدة داخل المؤسسة نفسها.

- الكود فريد داخل المؤسسة.
- الحالات: `active / inactive`.
- يمنع نقل المسار إلى مولدة أخرى إذا كان مرتبطًا بمشتركين بصورة تكسر العلاقات.

### generator_subscribers

يمثل المشترك الحقيقي ويرتبط بمولدة إلزاميًا، وبمسار اختياريًا.

- رقم الحساب فريد داخل المؤسسة.
- رقم العداد فريد داخل المؤسسة عندما يكون موجودًا.
- الحالات: `active / suspended / disconnected`.
- يتحقق السيرفر أن المسار، إن وجد، تابع للمولدة المختارة داخل Tenant نفسه.

## عزل المؤسسات

- لا يقبل السيرفر `tenant_id` من تطبيق Flutter في عمليات المجال.
- جميع الاستعلامات والكتابات تستخدم `tenantId` المستخرج من Access Token.
- لا يمكن ربط مولدة أو مسار أو مشترك من مؤسسة ثانية.
- جميع العلاقات والتحقق من الأهداف تتم داخل معاملة وقواعد السيرفر.

## التخصيصات الحقيقية

في Stage02 كان الهدف مرجعًا نصيًا. في Stage03:

1. يرسل التطبيق `type` و`target_id` فقط.
2. يتحقق السيرفر من وجود الهدف وحالته داخل Tenant.
3. يشتق السيرفر الاسم والبيانات الوصفية، ولا يثق بـ`label` أو `metadata` المرسلة من العميل.
4. تخصيص مسار يجعل الجابي يرى المشتركين النشطين ضمن ذلك المسار.
5. تخصيص مولدة يجعل الجابي يرى المولدة والمسارات والمشتركين التابعين لها بحسب عقد العرض.
6. تخصيص مشترك مباشر يظهر ذلك المشترك فقط مع المولدة والمسار المرتبطين به.

## الحذف والحفاظ على العلاقات

لا يوجد حذف صلب في Stage03. التغيير يتم بالحالة حتى لا تضيع العلاقات وسجلات التدقيق. فتح الحذف لاحقًا يحتاج سياسة أرشفة وترحيل مستقلة.

## Offline Foundation في Flutter

- يحتفظ التطبيق بآخر قوائم مؤكدة للمولدات والمسارات والمشتركين داخل SQLite عبر `app_meta`.
- عند فشل الاتصال تعرض الواجهة آخر نسخة محلية ناجحة مع تنبيه واضح.
- عمليات المجال الحالية تحتاج اتصالًا بالسيرفر؛ Queue المالية لم تُفتح.
- الجابي يخزن آخر Domain مخصص له للعرض الميداني بدون إنترنت.

## حدود المرحلة

- لا قراءة عداد.
- لا تسعير أمبير أو دورة فاتورة.
- لا جباية كاملة أو جزئية.
- لا دين أو وصل أو مصروف أو وقود أو ربح.
- لا GPS أو إشعارات أو طباعة أو واتساب.
- لا ربط ببرنامج الحاسبة.
