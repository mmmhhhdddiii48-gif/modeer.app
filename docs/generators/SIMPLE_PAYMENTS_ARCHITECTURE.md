# معمارية Stage06 — التسديد البسيط

## المسار

```text
فاتورة غير مسددة
→ تسجيل دفعة
→ تحديث المدفوع والمتبقي
→ إظهار رقم الوصل داخل نفس الفاتورة
```

## البيانات

- الفاتورة نفسها تحفظ الإجمالي والمدفوع والمتبقي والحالة.
- جدول `generator_invoice_payments` يحفظ الدفعات وأرقام الوصولات فقط.
- لا يوجد دفتر ذمم مستقل.
- لا توجد شاشة صندوق منفصلة.
- لا توجد مراجعة أو اعتماد إضافي.

## الحماية

- لا تقبل دفعة أكبر من المتبقي.
- الفاتورة المسددة لا تقبل دفعة جديدة.
- `operation_uuid` يمنع تكرار نفس الدفعة عند إعادة الإرسال.
- الوصولات متسلسلة وفريدة داخل المؤسسة.
- لا حذف أو تعديل أو إرجاع دفعة في هذه المرحلة.
